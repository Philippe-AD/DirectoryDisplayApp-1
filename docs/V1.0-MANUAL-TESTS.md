# Matrice de Tests Manuels — DirectoryDisplayApp V1.0

Ce document recense la suite complète des 25 parcours de test manuels exécutés sur l'application empaquetée Windows (installateur NSIS et version portable) pour valider la release V1.0.0.

---

## 📊 Matrice de Validation Manuelle des Parcours Utilisateurs

| ID | Parcours / Test | Préparation | Action | Résultat attendu | Résultat observé | Statut |
|---|---|---|---|---|---|---|
| **TM-01** | Premier démarrage | Lancer l'application empaquetée v1.0.0 sans serveur dev. | Exécuter l'application. | Affichage propre de l'écran d'accueil avec indicateur Mode Protégé et liste des lecteurs. | Écran d'accueil affiché avec version v1.0.0, sans erreur dans la console. | 🟢 Validé |
| **TM-02** | Exploration d'un dossier | Sélectionner un dossier de test. | Cliquer sur un sous-dossier pour le déployer. | Le dossier se déploie à la demande sans dupliquer les éléments. | Le contenu s'affiche avec la bonne indentation et chargement fluide. | 🟢 Validé |
| **TM-03** | Sélection d'un fichier & Aperçu texte | Sélectionner un fichier `.txt` ou `.md`. | Cliquer sur `notes.txt`. | Affichage instantané du texte avec coloration et nombre de lignes. | Le contenu texte apparaît clairement dans le panneau avec numérotation. | 🟢 Validé |
| **TM-04** | Aperçu image | Sélectionner `petite-image.png`. | Cliquer sur le fichier PNG. | Affichage de l'image centrée avec dimensions et bouton de zoom. | L'image s'affiche proprement sans déformation ni dépassement. | 🟢 Validé |
| **TM-05** | Aperçu PDF | Sélectionner un document `.pdf`. | Cliquer sur `document.pdf`. | Intégration du visualiseur PDF natif ou iframe sécurisé. | Le document PDF s'affiche sans erreur d'origine ni blocage. | 🟢 Validé |
| **TM-06** | Aperçu média | Sélectionner un fichier `.mp3` ou `.mp4`. | Cliquer sur le fichier média. | Affichage du lecteur audio/vidéo HTML5. Pas d'autoplay. | Le lecteur s'affiche sur pause et démarre à la demande. | 🟢 Validé |
| **TM-07** | Aperçu DOCX | Sélectionner `rapport.docx`. | Cliquer sur le document Word. | Rendu du document via `docx-preview`. Neutralisation XSS. | Le rendu HTML est propre sans exécution de scripts non autorisés. | 🟢 Validé |
| **TM-08** | Format inconnu | Sélectionner un fichier `.dat` ou `.bin`. | Cliquer sur le fichier. | Affichage d'une carte d'informations neutre indiquant un aperçu indisponible. | Carte d'informations affichée correctement sans crash de l'UI. | 🟢 Validé |
| **TM-09** | Ouverture externe | Sélectionner un fichier de test. | Cliquer sur "Ouvrir avec...". | Avertissement d'ouverture externe affiché. Confirmation requise. | L'application système par défaut s'ouvre après validation explicite. | 🟢 Validé |
| **TM-10** | Renommage | Sélectionner un fichier réinscriptible dans le dossier de test. | Cliquer sur "Renommer", saisir un nouveau nom valide. | Le fichier est renommé sur le disque et le TreeView s'actualise. | Fichier réellement renommé sur le système et dans l'arborescence. | 🟢 Validé |
| **TM-11** | Annulation renommage | Après un renommage réussi (TM-10). | Cliquer sur "Annuler l'action". | L'ancien nom est restauré sur le disque et dans l'interface. | Fichier restauré à son nom d'origine immédiatement. | 🟢 Validé |
| **TM-12** | Copie | Sélectionner un fichier source et un dossier destination. | Démarrer l'assistant "Créer une copie...". | Le fichier source est conservé et la copie apparaît dans la destination. | Fichier source et copie présents simultanément sur le disque. | 🟢 Validé |
| **TM-13** | Annulation copie | Après une copie réussie (TM-12). | Cliquer sur "Annuler la copie". | Le fichier copie est supprimé, le fichier source reste inchangé. | La copie disparaît sans altérer le fichier d'origine. | 🟢 Validé |
| **TM-14** | Déplacement | Sélectionner un fichier source et un dossier cible. | Exécuter "Déplacer vers...". | Le fichier est retiré de la source et apparaît dans la cible. | Déplacement effectif sur le disque dur. | 🟢 Validé |
| **TM-15** | Annulation déplacement | Après un déplacement (TM-14). | Cliquer sur "Annuler le déplacement". | Le fichier retourne à son emplacement initial. | Ancien emplacement et arborescence restaurés. | 🟢 Validé |
| **TM-16** | Conflit de nom | Tenter de renommer ou copier vers un nom déjà existant. | Saisir un nom déjà présent dans le dossier cible. | Message d'erreur explicite sans écrasement silencieux. | Refus avec avertissement clair d'anti-écrasement. | 🟢 Validé |
| **TM-17** | Mise à la Corbeille | Sélectionner un fichier dans le dossier de test. | Cliquer sur "Mettre à la Corbeille". | Modal de confirmation requise. Déplacement vers la Corbeille Windows. | Fichier déplacé dans la Corbeille Windows sans suppression définitive. | 🟢 Validé |
| **TM-18** | Refus racine lecteur | Tenter de renommer ou déplacer la racine `C:\`. | Cibler `C:\` dans une opération. | Refus immédiat avec le code `DRIVE_ROOT_PROTECTED`. | Opération bloquée avec message explicatif réconfortant. | 🟢 Validé |
| **TM-19** | Refus dossier système | Tenter de renommer ou corbeille sur `C:\Windows`. | Cibler `C:\Windows` ou `C:\Program Files`. | Refus immédiat avec le code `SYSTEM_PATH_PROTECTED`. | Bloqué avec message de sécurité OS. | 🟢 Validé |
| **TM-20** | Navigation au clavier | Naviguer sans la souris. | Utiliser `Tab`, `Flèches`, `Entrée`, `Échap`. | Focus visible, ouverture par Entrée, fermeture de modal par Échap. | Navigation fluide au clavier sans piège de focus. | 🟢 Validé |
| **TM-21** | Thème sombre | Basculer le thème de l'application en mode sombre. | Cliquer sur l'interrupteur Thème. | Les couleurs de l'interface et du volet d'aperçu passent en mode sombre. | Thème sombre lisible et persistant au redémarrage. | 🟢 Validé |
| **TM-22** | Petite fenêtre | Redimensionner la fenêtre à la largeur minimale (e.g. 800x600). | Réduire la taille de la fenêtre Electron. | Les panneaux s'adaptent avec barres de défilement sans chevauchement. | Interface responsive fonctionnelle sans cassure. | 🟢 Validé |
| **TM-23** | Version installée | Exécuter l'installateur `DirectoryDisplayApp Setup 1.0.0.exe`. | Lancer le programme d'installation NSIS. | Installation rapide dans `%LocalAppData%\Programs`, raccourci créé. | Application installée et fonctionnelle sans droits administrateur. | 🟢 Validé |
| **TM-24** | Version portable | Exécuter la version portable `DirectoryDisplayApp 1.0.0.exe`. | Lancer l'exécutable portable direct. | Démarrage instantané sans installation préalable. | Fonctionnement complet autonome sans dépendance de dev. | 🟢 Validé |
| **TM-25** | Désinstallation | Désinstaller depuis les Paramètres Windows. | Lancer la désinstallation. | Suppression complète des fichiers installés et raccourcis. | Désinstallation propre sans fichiers résiduels anormaux. | 🟢 Validé |
