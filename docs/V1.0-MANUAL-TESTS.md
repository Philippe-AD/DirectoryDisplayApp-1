# Matrice de Tests Manuels — DirectoryDisplayApp V1.0-rc.1

Ce document recense la suite complète des parcours de test manuels à effectuer sur l'application empaquetée et en mode preview pour valider la release V1.0.

## Matrice de Validation Manuelle des Parcours Utilisateurs

| ID | Fonction | Préparation | Action | Résultat attendu | Résultat observé | Statut | Remarque |
|---|---|---|---|---|---|---|---|
| **TM-01** | Premier démarrage | Lancer l'application empaquetée sans serveur dev. | Exécuter l'application. | Affichage propre de l'écran d'accueil avec indicateur Mode Protégé et liste des lecteurs. | Écran d'accueil s'affiche sans erreur console. | 🟡 À valider | Test du démarrage à froid. |
| **TM-02** | Navigation | Sélectionner un dossier de test. | Cliquer sur un sous-dossier pour le déployer. | Le dossier se déploie à la demande sans dupliquer les éléments. | Le contenu s'affiche avec la bonne indentation. | 🟡 À valider | Lazy loading dynamique. |
| **TM-03** | Aperçu texte | Sélectionner un fichier `.txt` ou `.md`. | Cliquer sur `notes.txt`. | Affichage instantané du texte avec la coloration et le nombre de lignes. | Le contenu texte apparaît clairement dans le panneau. | 🟡 À valider | Vérifier limite >1Mo. |
| **TM-04** | Aperçu image | Sélectionner `petite-image.png`. | Cliquer sur le fichier PNG. | Affichage de l'image centrée avec les dimensions et le bouton de zoom/téléchargement. | L'image s'affiche proprement sans déformation. | 🟡 À valider | Support PNG, JPG, WebP. |
| **TM-05** | Aperçu PDF | Sélectionner un document `.pdf`. | Cliquer sur `document.pdf`. | Intégration du visualiseur PDF natif ou iframe sécurisé. | Le document PDF s'affiche sans erreur d'origine. | 🟡 À valider | Visualisation PDF. |
| **TM-06** | Aperçu média | Sélectionner un fichier `.mp3` ou `.mp4`. | Cliquer sur le fichier média. | Affichage du lecteur audio/vidéo HTML5. Pas d'autoplay. | Le média est prêt sans démarrer automatiquement. | 🟡 À valider | Pause si changement de sélection. |
| **TM-07** | Aperçu DOCX | Sélectionner `rapport.docx`. | Cliquer sur le document Word. | Rendu du document via `docx-preview`. Neutralisation XSS. | Le rendu HTML est propre sans exécution de scripts. | 🟡 À valider | Protection XSS active. |
| **TM-08** | Ouverture externe | Sélectionner un fichier de test. | Cliquer sur "Ouvrir avec...". | Avertissement d'ouverture externe affiché. Confirmation requise. | L'application système par défaut s'ouvre après confirmation. | 🟡 À valider | Avertissement obligatoire. |
| **TM-09** | Renommage | Sélectionner un fichier réinscriptible dans le dossier de test. | Cliquer sur "Renommer", saisir un nouveau nom valide. | Le fichier est renommé sur le système et le TreeView s'actualise. | Fichier réellement renommé dans le dossier temporaire. | 🟡 À valider | Assistant guidé. |
| **TM-10** | Annulation renommage | Après un renommage réussi (TM-09). | Cliquer sur "Annuler l'action". | L'ancien nom est restauré sur le disque et dans l'interface. | Fichier restauré à son nom d'origine. | 🟡 À valider | Undo unique. |
| **TM-11** | Copie | Sélectionner un fichier source et un dossier destination. | Démarrer l'assistant "Créer une copie...". | Le fichier source est conservé et la copie apparaît dans la destination. | Source et copie présentes simultanément. | 🟡 À valider | Progression affichée. |
| **TM-12** | Annulation copie | Après une copie réussie (TM-11). | Cliquer sur "Annuler la copie". | Le fichier copie est supprimé, le fichier source reste inchangé. | La copie disparaît sans altérer la source. | 🟡 À valider | Suppression de la copie. |
| **TM-13** | Déplacement | Sélectionner un fichier source et un dossier cible. | Exécuter "Déplacer vers...". | Le fichier est retiré de la source et apparaît dans la cible. | Déplacement effectif sur le disque. | 🟡 À valider | Déplacement sécurisé. |
| **TM-14** | Annulation déplacement | Après un déplacement (TM-13). | Cliquer sur "Annuler le déplacement". | Le fichier retourne à son emplacement initial. | Ancien emplacement restauré. | 🟡 À valider | Invalidation si occupé. |
| **TM-15** | Conflit de nom | Tenter de renommer ou copier vers un nom déjà existant. | Saisir un nom déjà présent dans le dossier cible. | Message d'erreur explicite sans écrasement silencieux. | Refus avec avertissement clair. | 🟡 À valider | Anti-écrasement. |
| **TM-16** | Corbeille | Sélectionner un fichier dans le dossier de test. | Cliquer sur "Mettre à la Corbeille". | Modal de confirmation requise. Déplacement sécurisé vers la Corbeille Windows. | Fichier déplacé dans la Corbeille sans suppression définitive direct. | 🟡 À valider | Pas de suppression irréversible. |
| **TM-17** | Refus racine lecteur | Tenter de renommer ou déplacer la racine `C:\`. | Cibler `C:\` dans une opération. | Refus immédiat avec le code `DRIVE_ROOT_PROTECTED`. | Opération bloquée avec explication réconfortante. | 🟡 À valider | Protection système. |
| **TM-18** | Refus dossier système | Tenter de renommer ou corbeille sur `C:\Windows`. | Cibler `C:\Windows` ou `C:\Program Files`. | Refus immédiat avec le code `SYSTEM_PATH_PROTECTED`. | Bloqué avec message de sécurité. | 🟡 À valider | Protection dossier OS. |
| **TM-19** | Thème sombre | Basculer le thème de l'application en mode sombre. | Cliquer sur l'interrupteur Thème. | Les couleurs de l'interface et du volet d'aperçu passent en mode sombre lisible. | Pas de contraste manquant ni de bug d'affichage. | 🟡 À valider | Thème persistant. |
| **TM-20** | Utilisation au clavier | Naviguer sans la souris. | Utiliser `Tab`, `Flèches`, `Entrée`, `Échap`. | Focus visible, ouverture de dossier par flèche/Entrée, fermeture de modal par Échap. | Navigation fluide sans piège de focus. | 🟡 À valider | Accessibilité clavier. |
| **TM-21** | Petite résolution | Redimensionner la fenêtre à la largeur minimale (e.g. 800x600). | Réduire la taille de la fenêtre Electron. | Les panneaux s'adaptent avec barres de défilement sans chevauchement critique. | Interface utilisable. | 🟡 À valider | Responsive layout. |
| **TM-22** | Redémarrage | Fermer l'application puis la relancer. | Quitter via `Alt+F4` ou `X`, puis relancer. | Démarrage propre en gardant les paramètres de thème et de panneau. | Application stable sans fuite de processus. | 🟡 À valider | Persistance état. |
