# 🚀 Notes de Version — DirectoryDisplayApp 1.0.0

**Date de publication** : 25 Juillet 2026  
**Plateforme** : Windows 10 / 11 (x64)

---

## 📌 Présentation

**DirectoryDisplayApp 1.0.0** est la première version stable officielle de notre explorateur de fichiers guidé et sécurisé pour Windows.
Conçu pour les utilisateurs recherchant la sérénité lors de la gestion de leurs fichiers, DirectoryDisplayApp élimine les fausses manipulations grâce à une interface visuelle claire, des assistants étape par étape et une protection permanente de vos dossiers système.

---

## ✨ Ce que permet cette version

* 📂 **Exploration visuelle claire** : Visualisez vos dossiers dans une arborescence hiérarchique extensible sans risque de vous perdre.
* 👁️ **Visualiseur instantané** : Prévisualisez directement vos photos, documents PDF, fichiers texte, vidéos, musiques et documents Word (`.docx`) sans ouvrir d'autre application.
* ✏️ **Renommage assisté** : Modifiez le nom d'un fichier avec vérification automatique pour éviter tout doublon.
* 📋 **Copie et déplacement guidés** : Transférez vos fichiers vers d'autres dossiers avec confirmation claire et barre de progression.
* 🗑️ **Envoi à la Corbeille sécurisé** : Mettez vos fichiers indésirables à la Corbeille Windows en toute simplicité.
* ↩️ **Bouton d'annulation (Undo)** : Annulez instantanément la dernière copie, le dernier déplacement ou le dernier renommage si vous avez commis une erreur.
* 🔍 **Recherche rapide** : Retrouvez immédiatement un fichier parmi les répertoires explorés.

---

## 🛡️ Sécurité et Confiance

DirectoryDisplayApp place la protection de vos données au premier plan :
1. **Aucune modification par simple navigation** : Parcourir un fichier ou un dossier ne risque jamais d'altérer vos données.
2. **Confirmation explicite** : Aucune action de copie, déplacement ou renommage n'est exécutée sans votre validation.
3. **Aucun écrasement silencieux** : L'application refuse de remplacer un fichier existant si un nom identique est détecté.
4. **Aucune suppression définitive** : Les éléments supprimés sont envoyés dans la Corbeille Windows officielle, d'où vous pourrez toujours les restaurer.
5. **Protection des dossiers sensibles** : Les répertoires Windows vitaux (comme `C:\Windows`) sont automatiquement verrouillés contre toute modification accidentelle.
6. **Messages clairs et rassurants** : L'application vous informe toujours du résultat de votre action et vous offre la possibilité de l'annuler.

---

## ⚠️ Limites Importantes

* **Windows uniquement** : Cette version est développée spécifiquement pour le système d'exploitation Windows.
* **Opérations fichier par fichier** : Les opérations s'effectuent un élément à la fois pour garantir une sécurité maximale.
* **Pas de glisser-déposer** : Pour éviter toute erreur de manipulation involontaire, le transfert s'effectue via l'assistant de copie/déplacement.
* **Aperçus des très gros fichiers** : Pour protéger la mémoire de votre ordinateur, les fichiers texte de plus de 1 Mo ne s'affichent pas dans l'aperçu.

---

## 📦 Installation & Fichiers de Distribution

Deux formats d'installation sont mis à votre disposition selon votre besoin :

1. **Installateur classique Windows** : `DirectoryDisplayApp Setup 1.0.0.exe`
   * Double-cliquez sur le fichier pour installer l'application sur votre ordinateur.
   * Ajoute l'application à votre menu Démarrer et permet une désinstallation propre depuis le Panneau de configuration Windows.
   * N'exige aucun droit d'administrateur.

2. **Version Portable** : `DirectoryDisplayApp 1.0.0.exe`
   * Ne nécessite aucune installation.
   * Peut être exécutée directement depuis une clé USB ou n'importe quel dossier.

> *Note Windows SmartScreen : Si Windows affiche un avertissement de sécurité lors du premier lancement, cliquez sur "Informations complémentaires" puis "Exécuter quand même". L'application est sûre et saine.*
